# Peaceful Music

Drop 2-5 calm instrumental tracks here (mp3 / wav / m4a). The pipeline picks one randomly per video and plays it at 5% volume under the narration.

## Free sources

- **Pixabay Music — Calm/Meditation**: https://pixabay.com/music/search/peaceful/  (direct download, no signup)
- **YouTube Audio Library — Calm**: https://studio.youtube.com → Audio Library → filter Mood: Calm
- **Free Music Archive — Ambient**: https://freemusicarchive.org/genre/Ambient/

## Mood guidance for natural health channel

- Soft piano / acoustic guitar
- Gentle strings (no swelling crescendos)
- Light nature sounds (water, wind) optional
- **AVOID**: cinematic dramatic, percussion-heavy, anything with vocals

You can drop any mp3 here. The pipeline auto-detects on next run.
